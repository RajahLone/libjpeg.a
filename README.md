# libjpeg.a

From The Independent JPEG Group's JPEG : libjpeg 10.0.0 to /opt/cross-mint/m68k-atari-mint/lib/

Config: see jconfig.h (Atari ST target), uses jmemnobs.c (no backup in tmpfile, assumes there is enough memory).

Targets: 68000, 68020-060, ColdFire

# installation for makefiles

- /opt/cross-mint/m68k-atari-mint already installed 

- libmbedtls.xcodeproj is for Xcode 26.3, you may not need it if you use something else.
